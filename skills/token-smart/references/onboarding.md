# Token Smart 已安装

省的是无效消耗，不是该做的工作。

这是一个**三层 token 经济**技能，按层按需加载，平时只用到第一层：

| 层 | 解决什么 | 什么时候用 |
| --- | --- | --- |
| ① 活跃期 | 少读、少重复检查、少过程播报 | 默认，任何任务 |
| ② 存留期 | 旧历史冷存，默认不加载，需要时按原话检索 | 任务变慢／加载失败／要回看旧记录 |
| ③ 演进期 | 离线复盘过去会话，收敛技能与记忆 | 要夜间／离线自优化 |

**原理**：按需读取文件与技能，复用已有证据和实现；能用脚本判断的就用脚本；检查通过后结束重复检查；只在有收益时增加推理、审阅和子任务。

**使用体感**：过程播报更少，答案先给结果，小任务不再套一整套流程；长任务优先接着有效进展做。你要求的详细分析、完整代码和必要测试仍会保留。

默认按需使用。Codex 可输入 `$token-smart`，Claude Code 可输入 `/token-smart`；也可以说"这次按 Token Smart 来"。安装时加 `--activate` 会把短规则加入对应工具的指令文件，供后续会话读取，不会修改模型或额度设置。若当前会话尚未发现新技能，请新开会话。

随时说"这次详细展开"即可增加说明；说"这次不要按省 Token 模式"即可覆盖本次偏好。卸载技能及其未修改的常驻规则时，运行安装器，保留相同的目标与自定义路径参数，改用 `--uninstall`，不要同时加 `--activate`。

这是工作方式与存储约定，不是压缩算法、额度解锁或固定折扣。节省幅度取决于任务、上下文、模型和宿主；**本包未给出受控对照下的节省比例**。
